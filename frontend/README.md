# Customer Feedback Analyzer frontend

The React dashboard for the AI Customer Feedback Analyzer. It lets users submit NPS feedback, then displays response metrics, sentiment distribution, common themes, and follow-up workload.

## Run locally

1. Start the FastAPI backend at `http://127.0.0.1:8000`.
2. Install dependencies with `npm install`.
3. Start the dashboard with `npm run dev`.

The Vite development server runs at `http://localhost:5173`, which is enabled by the backend CORS configuration.

## Available commands

- `npm run dev` — start the development server.
- `npm run build` — create a production build.
- `npm run lint` — run ESLint.
